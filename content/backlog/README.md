# Starter backlog

Ready-to-post material mined from the repo's research trail, so the account
never starves while the daily engine warms up. Threads live one per file in
`threads/`; singles and 2-3 part shorts live in `singles.md`.

How to use it:
- Post threads no more than ~1 per week. They are the reputation builders;
  the daily stat/idea posts are the growth engine.
- Everything here is pre-sanitized: R and percentages instead of dollars,
  live thresholds and filter parameters blurred, no tickers from the
  overflow tier, no identity strings. If you edit a post, keep it that way.
  The queue lint (`scripts/lint_posts.py`) is the reference for what blocks.
- Dollar figures from the ledger are all computed on a flat modeling basis,
  never the real account. If a post needs a dollar number, say "on a flat
  backtest basis" once and prefer R everywhere else.
- Cross the item off here when it goes out, and note the date. Repetition
  control for backlog material is manual (the queue lint only sees ideas).

Source of truth for the stories is the repo itself (CLAUDE.md, the negative
registry, scratch/ultracode_research). If a number here disagrees with the
repo, the repo wins; re-check before posting anything that feels off.
