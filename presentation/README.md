# The Book — presentation

A deck about the trading system, built for a smart-generalist (hybrid) audience:
what it does, why it works, and how it runs end to end.

## Deliverables

| File | What it is |
|---|---|
| `deck.html` | Self-contained HTML deck. Open in any browser. `←/→` navigate, `N` speaker notes, `F` fullscreen. No network, no dependencies. |
| `The_Book.pptx` | Native, editable PowerPoint. Text is real text; figures are embedded images; speaker notes are in the notes pane. |
| `The_Book_deck.pdf` | Flat PDF export (one slide per page) for quick sharing. |
| `deck_short.html` / `The_Book_Short.pptx` / `The_Book_Short_deck.pdf` | The short offshoot deck (cover + 6 slides, under 30 minutes with questions): process, strategies, edge persistence, returns, and correlation to SPY over time. Built from `deck_spec_short.json` (generated by `write_spec_short.py`). |
| `deck_cards.html` / `The_Book_Cards.pptx` / `The_Book_Cards_deck.pdf` | Strategy-cards deck: one slide per STRATEGY_BOOK entry (13 incl. the 3x Bear fade pilot), reported like the site's signal cards — objective, key filters, and an execution card (entry / stop / target / time exit / risk / special handling / stats). Built from `deck_spec_cards.json` (generated by `write_spec_cards.py`); card data lives in `CARDS` in `build_deck_html.py` and must be kept consistent with `strategy_config.py`. |

## Single source of truth

`deck_spec.json` holds all slide content (titles, bullets, callouts, speaker notes,
and which `figure` each slide uses). **Edit the content there, then rebuild** — both
the HTML and the PPTX regenerate from it. The full spec is generated by
`write_spec_v2.py`, the short spec by `write_spec_short.py`; both builders take
optional `[spec.json] [out]` arguments and default to the full deck:

```bash
python presentation/write_spec_short.py
python presentation/build_deck_html.py presentation/deck_spec_short.json presentation/deck_short.html
python presentation/build_deck_pptx.py presentation/deck_spec_short.json presentation/The_Book_Short.pptx
```

The short deck's `rolling_corr` figure embeds a rolling 36-month correlation of
book monthly returns (flat $750k, PnL booked at exit) vs SPY, computed from
`data/backtest_trades_full.parquet` + `master_prices.parquet`. The series is a
literal (`ROLL36`) in `build_deck_html.py`; recompute and repaste it if the
ledger changes materially.

## Rebuild

```bash
# 1. HTML (also the source of the figure rendering)
python presentation/build_deck_html.py            # -> deck.html

# 2. Figures (only needed if a figure or its data changed)
python presentation/build_figures.py              # -> figs/<id>.html
#    screenshot each figs/<id>.html at 2x (headless Chrome), then:
python presentation/crop_figs.py                  # tight-crops figs/<id>.png

# 3. PowerPoint (embeds figs/<id>.png + native text)
python presentation/build_deck_pptx.py            # -> The_Book.pptx

# 4. PDF (optional)
#    headless Chrome --print-to-pdf on deck.html  -> The_Book_deck.pdf
```

Figure stats (the 12-strategy table, scatter, expectancy bars) live in `STRATS`
inside `build_deck_html.py` — the same numbers as `strategy_config.py`'s
`STRATEGY_BOOK`. Update there if the book changes.

## Notes
- Figures are rendered from the HTML so the two formats stay visually identical.
- `figs/` (html + png) are build intermediates kept so the PPTX can be rebuilt
  without re-screenshotting.
